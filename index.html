⚙️ Game Logic & State Machine

Branching CYOA Game Engine

Write a Python command-line Choose Your Own Adventure game called 'The Hacker's Heist'.
Requirements:
1. Implement a Player class tracking HP, stealth percentage, credits, and inventory list.
2. Structure story nodes in a graph with choices that lead to different nodes.
3. Include dynamic actions that modify player state (damage, healing, items gained).
4. Implement at least 4 distinct endings (Architect, Ghost, Mercenary, Meltdown) and a game_over state when HP reaches 0.
5. Provide a mock_inputs hook in play_game() for automated headless unit testing.
🧪 Test-Driven Engineering

Comprehensive Pytest Verification Suite

Write a complete Pytest test suite for our Choose Your Own Adventure game.
Follow the Arrange-Act-Assert (AAA) pattern to test:
- Initial player attributes and inventory initialization
- Take damage and heal boundary limits (capped at 100, floored at 0)
- Duplicate item prevention and item removal checks
- Story graph integrity (verify every option target exists in the story graph)
- Full branch simulation reaching the 'ending_architect' victory
- Full branch simulation triggering a 'game_over' health depletion.
